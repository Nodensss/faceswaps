# Известные ограничения FaceSwapLocal

Дата актуализации: 19.07.2026; состояние после этапа B.

- Реализован только сырой квадратный neural crop. Inverse transform, маска,
  цветосогласование и вставка в целевое фото относятся к этапу C.
- HyperSwap 1a 256 численно совпадает с FaceFusion, но на трёх синтетических parity-
  парах переносит identity заметно слабее InSwapper. Поэтому текущий UI-default —
  `inswapper_128_fp16`; HyperSwap остаётся основным кандидатом shortlist до проверки
  на расширенном лицензированном наборе.
- Полный FaceFusion production flow может уточнять пять точек через 68-point
  landmarker. Этап B сравнивает одинаковую цепочку с исходными пятью точками YOLO на
  desktop и Android; refined landmarks ещё не подключены.
- Android использует closed-form least-squares affine и bilinear sampling вместо
  FaceFusion/OpenCV RANSAC и `INTER_AREA`. На текущем наборе это проходит строгий
  parity, но сложные ракурсы должны расширить golden-набор до этапа C.
- ONNX Runtime 1.26.0 завершает процесс нативным `SIGABRT` при создании XNNPACK-
  сессии InSwapper на API 35 x86_64 AVD. Пользовательский путь закреплён на CPU;
  известные x86 ABI превентивно получают CPU fallback, а XNNPACK нельзя считать
  поддержанным до отдельной проверки на реальном ARM64-устройстве.
- Benchmark, peak heap, thermal и повторные циклы на физическом reference device не
  выполнены: подключённого Android-телефона не было. Результаты AVD не являются
  прогнозом производительности телефона.
- Проверка полного SHA-256 перед каждой model session намеренно увеличивает холодное
  время запуска inference, особенно на эмуляторе. Оптимизация без ослабления проверки
  целостности требует отдельного проектного решения.
- Лицензионные условия весов не дают достаточного основания для их распространения:
  модели не входят в Git/APK и импортируются пользователем локально. Детали находятся
  в `docs/MODEL_CARD.md` и `THIRD_PARTY_NOTICES.md`.
- Face parsing/occlusion mask, GFPGAN 1.4, экспорт, видео и release-оптимизация ещё не
  реализованы; они принадлежат последующим этапам C–G.
