# FaceSwapLocal

Личное Android-приложение для локальной замены одного или нескольких лиц.
Фотографии не загружаются в интернет: в манифесте намеренно нет разрешения
`INTERNET`, а детектор лиц поставляется внутри APK.

Полное задание для автономной работы Codex находится в
[`TECHNICAL_SPEC.md`](TECHNICAL_SPEC.md).

## Что работает после этапа C

- выбор фотографии с лицами-источниками;
- выбор целевой фотографии через системный Photo Picker;
- локальная загрузка изображений с ограничением размера в памяти;
- обнаружение нескольких лиц на обеих фотографиях;
- рамки и номера обнаруженных лиц;
- независимое назначение источника для каждого целевого лица;
- локальный импорт официальных ONNX-весов с проверкой полного SHA-256;
- независимые YOLOFace 5-point alignment и ArcFace identity embedding;
- настоящий InSwapper 128 fp16 inference через ONNX Runtime с CPU fallback;
- вставка заменённого лица в исходное разрешение цели: inverse affine transform,
  Gaussian-feathered mask, цветосогласование и мягкий blending;
- полный сценарий «один источник → одно целевое лицо» с результатом в памяти;
- parity с FaceFusion 3.7.1 для геометрии, сырого crop и финального кадра;
- понятные состояния загрузки и ошибок;

Текущий полный neural-сценарий этапа C намеренно ограничен одной парой лиц. Несколько
источников/целей относятся к этапу D; restoration, улучшенная маска, сравнение и
экспорт — к этапу E. Веса моделей не входят в Git или APK.

## Как запустить

1. Откройте корневую папку в Android Studio.
2. Используйте JDK 17 и установите Android SDK 35.
3. Дождитесь Gradle Sync.
4. Запустите конфигурацию `app` на Android 9 (API 28) или новее.

Командная строка:

```bash
./gradlew test
./gradlew lint
./gradlew assembleDebug
```

Debug APK появится в `app/build/outputs/apk/debug/`.

## План развития

1. Этап D: несколько источников и независимых целевых лиц.
2. Этап E: GFPGAN 1.4, parsing/occlusion mask, настройки качества, сравнение и экспорт.
3. Этап F: декодирование видео, трекинг, стабилизация, кодирование и сохранение аудио.
4. Этап G: release-сборка и финальная приёмка.

## Приватность

Проект не запрашивает сетевой доступ. Системный Photo Picker выдаёт приложению
доступ только к выбранным файлам. Перед добавлением сторонней модели нужно
проверить её лицензию и происхождение весов.
