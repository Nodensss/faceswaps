# FaceSwapLocal

Личное Android-приложение для локальной замены одного или нескольких лиц.
Фотографии не загружаются в интернет: в манифесте намеренно нет разрешения
`INTERNET`, а детектор лиц поставляется внутри APK.

Полное задание для автономной работы Codex находится в
[`TECHNICAL_SPEC.md`](TECHNICAL_SPEC.md).

## Что работает после контрольной точки 1 этапа E2

- выбор фотографии с лицами-источниками;
- выбор целевой фотографии через системный Photo Picker;
- локальная загрузка изображений с ограничением размера в памяти;
- обнаружение нескольких лиц на обеих фотографиях;
- рамки и номера обнаруженных лиц;
- независимое назначение источника для каждого целевого лица;
- до 8 фотографий-источников, «Не менять» и подтверждаемое «Применить ко всем»;
- локальный импорт официальных ONNX-весов с проверкой полного SHA-256;
- независимые YOLOFace 5-point alignment и ArcFace identity embedding;
- настоящий InSwapper 128 fp16 inference через ONNX Runtime с CPU fallback;
- вставка заменённого лица в исходное разрешение цели: inverse affine transform,
  Gaussian-feathered mask, цветосогласование и мягкий blending;
- последовательная обработка нескольких назначений поверх накопленного результата;
- двухпроходный pipeline: все свапы, закрытие InSwapper, затем GFPGAN только для
  назначенных лиц;
- BiSeNet parser-mask для защиты волос/висков/бороды и границы восстановления;
- включение GFPGAN, сила восстановления `0…1` и выбор parser/box-маски в UI;
- сравнение исходника и результата переключателем «До/После» без автосохранения;
- прогресс с этапом, номером лица и общим количеством, блокировка повторного запуска
  и отмена на безопасной границе с освобождением сессий и удалением временных файлов;
- экспорт результата через `MediaStore` в альбом `Pictures/FaceSwapLocal` с именем
  `FaceSwapLocal_yyyyMMdd_HHmmss.ext`, JPEG с настраиваемым качеством или PNG;
- нейтральная отметка о редактировании и видимый водяной знак, включённый по
  умолчанию и отключаемый;
- миниатюра, альбом и системная кнопка «Открыть» после успешного сохранения;
- parity с FaceFusion 3.7.1 для геометрии, сырого crop и финального кадра;
- понятные состояния загрузки и ошибок;

Этап E1 закрыт на синтетическом parity-наборе. Реальные фото и производительность
должны быть повторно проверены на первом физическом reference device; веса моделей
не входят в Git или APK. Пресеты качества, identity strength, ручной feathering,
color auto/off и профилирование памяти остаются в этапе E2.

## Как запустить

1. Откройте корневую папку в Android Studio.
2. Используйте JDK 17 и установите Android SDK 35.
3. Дождитесь Gradle Sync.
4. Запустите конфигурацию `app` на Android 9 (API 28) или новее.

Командная строка:

```bash
./gradlew test
./gradlew lint
./gradlew assembleDebug
```

Debug APK появится в `app/build/outputs/apk/debug/`.

## План развития

1. Этап E2: пресеты качества, identity strength, feathering, color auto/off и memory
   profiling (экспорт, прогресс с отменой и cleanup уже сделаны).
2. Этап F: декодирование видео, трекинг, стабилизация, кодирование и сохранение аудио.
3. Этап G: release-сборка и финальная приёмка.

## Приватность

Проект не запрашивает сетевой доступ. Системный Photo Picker выдаёт приложению
доступ только к выбранным файлам. Перед добавлением сторонней модели нужно
проверить её лицензию и происхождение весов.
